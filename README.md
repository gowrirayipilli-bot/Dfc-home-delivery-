# DFC Home Delivery - Flutter

## Run
1. Install Flutter SDK.
2. Extract this project.
3. Open terminal in the project folder.
4. Run:
   flutter pub get
   flutter run

## Included
Home, Menu, Food Details, Cart, Checkout, Payment selection, Order Tracking, Profile.
